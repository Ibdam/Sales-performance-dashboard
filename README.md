# Power BI Sales Dashboard for US Retail Company

This project features a Power BI dashboard developed to analyze and visualize sales performance, profit margins, product category trends, and regional insights for a U.S.-based retail company.

## Key Features
- Sales by Region, Category, and Sub-Category
- Monthly and Yearly Sales Trends
- Top Performing Products
- Profit Analysis and KPI Cards
- Interactive Filters and Drill-downs

## Tools Used
- Power BI
- DAX
- Power Query
- Data Modeling

## Files
- `Sales Dashboard for US Company.pbix`: Main Power BI report file
- `screenshots/`: Preview images of the dashboard
